An academic management platform meant to fit "in the palm of your hand" (*na palma da mão*).

I designed the PostgreSQL schema from scratch and built the RESTful Spring Boot backend with role-based authentication. It runs containerized with Docker on Google Cloud Run and serves two clients: an Angular web app and a Kotlin Android app.
