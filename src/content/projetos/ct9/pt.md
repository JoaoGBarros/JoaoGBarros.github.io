Uma plataforma de gestão acadêmica pensada para caber "na palma da mão".

Modelei o schema PostgreSQL do zero e construí o backend RESTful em Spring Boot, com autenticação baseada em papéis. O backend roda containerizado com Docker no Google Cloud Run e atende dois clientes: um web em Angular e um app Android em Kotlin.
